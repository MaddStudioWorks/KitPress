# SelkoMadd Press Site

Static GitHub Pages press kit built with vanilla HTML/CSS/JS.

## Run locally

Open `index.html` directly, or use any tiny local web server.

## GitHub Pages

Push this folder to a repository, then enable GitHub Pages from the repository settings and point it to the branch/folder containing `index.html`.

## Assets

Current images are in `assets/images/`.

Create `assets/downloads/` and add these files when ready:

- `SelkoMadd_Press_Kit.zip`
- `SelkoMadd_Screenshots.zip`
- `SelkoMadd_Artwork.zip`
- `SelkoMadd_Factsheet.pdf`

The page already links to those names.

## Optional teaser video

When the teaser is ready, add it under `assets/video/` and insert a local `<video>` section. No third-party embed is required.
